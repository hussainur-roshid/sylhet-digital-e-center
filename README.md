# Sylhet Digital E-Center

**Official Website of Sylhet Head Post Office Digital E-Center**

This website provides information about the digital services offered by Sylhet Head Post Office Digital E-Center.

## Technologies Used
- React
- Vite
- Tailwind CSS
- JavaScript
- Lucide React

## Installation

```bash
npm install
npm run dev
```

npm run build
